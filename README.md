# Умный офис

Учебный проект по ПМ03 «Участие в разработке приложений взаимодействия с интеллектуальными
интегрированными системами» (МДК 03.01), специальность 09.02.08.

**Студент:** Боднар Михаил Дмитриевич
**Группа:** 54-15
**Номер по журналу:** 2

## Назначение проекта

Стенд «умного офиса» собран в GNS3. Датчики температуры и влажности работают в Node-RED на
`IOT-01`, отправляют показания в приёмник на `CTRL-01`, тот же поток управляет вентилятором
`FAN-01` по порогу 30 °C. Приёмник отдаёт метрики для Prometheus на `MON-01`, по ним построена
панель и настроены оповещения в Grafana. Показания и команды вентилятора параллельно пишутся в
SQLite на `DB-01` — там же лежит страница истории.

## Схема обмена данными

```
                    IOT-01 (Node-RED, :1880)
   inject TEMP-01 (23 °C, каждые 5 с) ─┬─► change: значения и время
   inject HUM-01  (46 %,  каждые 5 с) ─┘        │
                                               ├─► POST /api/readings ──► CTRL-01:8080 ──► /metrics
                                               │                                      │
                                               │                                      ▼
                                               │                        Prometheus (MON-01:9090)
                                               │                                      │
                                               │                                      ▼
                                               │                          Grafana (MON-01:3000)
                                               │                          панель + правила + письма
                                               │
                                               └─► POST /api/readings ──► DB-01:8081 ──► SQLite

   TEMP-01 ──► switch «TEMP > 30 C» ──► FAN ON / FAN OFF ──► POST /api/actuators ──► CTRL-01:8080
                                                          └─► POST /api/actuators ──► DB-01:8081
```

Что происходит по шагам:

1. Node-RED каждые 5 секунд отправляет в приёмник показания `TEMP-01` (серверная, °C) и `HUM-01`
   (рабочая зона, %). Значения фиксированные — 23 °C и 46 %.
2. Температура уходит в `switch`: если значение больше 30 °C, формируется команда `FAN ON`, иначе
   `FAN OFF`. Команда уходит на приёмник и в базу.
3. Приёмник хранит последнее принятое значение каждого датчика и отдаёт его в `/metrics` вместе с
   возрастом показаний в секундах.
4. Prometheus опрашивает `/metrics` раз в 5 секунд, Grafana строит по этим данным панель и считает
   правила оповещений.
5. Те же показания и команды вентилятора отправляются на `DB-01`, где приёмник из раздаточных
   файлов складывает их в таблицы `measurements` и `actuator_events`.

## Порядок запуска

1. В GNS3 открыть проект `22` и запустить все узлы, дождаться загрузки ВМ.
2. Проверить сеть с `WIN-01`: `ipconfig` (адрес `192.168.10.10/26`, шлюз `192.168.10.1`) и
   `ping 192.168.20.10 / 192.168.20.11 / 192.168.20.12 / 192.168.30.10`.
3. `CTRL-01` — приёмник:

   ```bash
   cd /root/practice4/ctrl
   sudo docker compose -f compose.yml up -d
   curl -s http://127.0.0.1:8080/health
   ```

4. `IOT-01` — Node-RED (поток уже лежит в томе контейнера):

   ```bash
   cd /root/practice4/iot
   sudo docker compose -f compose.yml up -d
   ```

5. `DB-01` — хранилище истории:

   ```bash
   cd ~/practice6
   sudo docker compose -f compose.yml up -d
   sudo docker compose -f compose.yml ps
   ```

6. `MON-01` — службы мониторинга:

   ```bash
   sudo systemctl status prometheus grafana
   ```

   Обе службы включены в автозагрузку.

## Проверка работоспособности

| Что проверяем | Как | Ожидаемый результат |
|---|---|---|
| Приёмник отвечает | `curl -s http://192.168.20.10:8080/health` | `{"status":"ok","version":3,...}` |
| Показания доходят | Grafana, панель «Office CTRL датчики и вентилятор» | 23 °C, 46 %, возраст показаний меньше 20 с |
| Метрики собираются | Prometheus → Status → Target health | цель `office-controller` в состоянии UP |
| Запись в историю | `http://192.168.20.12:8081/` | карточки обновляются, график пополняется |
| Вентилятор | Node-RED, кнопка «ТЕСТ: 33 C (нажать)» | состояние вентилятора переходит в ON, затем возвращается в OFF |
| Оповещения | Grafana → Alerting → Alert rules | три правила в состоянии Normal |

## Порог и оповещения

* Вентилятор включается, когда температура **больше 30 °C**; при 30.0 °C и ниже остаётся
  выключенным.
* Правила Grafana (папка `Office`, группа `office-sensors`, оценка каждые 10 с, Pending 0 с):
  * `TEMP-01: нет новых показаний более 20 с`;
  * `HUM-01: нет новых показаний более 20 с`;
  * `CTRL-01 недоступен (up = 0)`.
* Письма отправляются на контакт `office-email`. Настройки SMTP в репозиторий не выкладываются:
  `work7/grafana.ini` содержит только несекретные параметры, пароль приложения задан на самой ВМ.
