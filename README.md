Учебный проект по ПМ03 (МДК 03.01), специальность 09.02.08.

## О чём проект

Виртуальный офис в GNS3: сеть с двумя коммутаторами и маршрутизатором, четыре сервера РЕД ОС 8,
рабочее место администратора на Windows Server 2019. На серверах поднят Docker, на IOT —
Node-RED с датчиками температуры и влажности, на CTRL — приёмник показаний.

## Что где лежит

```
work1/   план офиса и логическая схема сети
work2/   сборка сети в GNS3: VLAN, маршрутизация, NAT (конфиги и скриншоты)
work3/   Docker и Nginx на РЕД ОС 8 (compose и скриншоты)
work4/   приёмник показаний и два датчика в Node-RED
work5/   вентилятор в Node-RED по датчику температуры
work6/   база SQLite на DB-01, приём показаний на 8081
work7/   Prometheus и Grafana на MON-01, метрики CTRL
reports/ отчёты №1–№7
journal.md  что делал по дням
```

Команды и порядок действий — в отчётах, они же и сдаются.

## Что работает сейчас

* TEMP-01 (серверная, 23 °C) и HUM-01 (рабочая зона, 46 %) отправляют показания каждые 5 секунд.
* Вентилятор FAN-01 включается при температуре выше 30 °C и выключается ниже.
  Показать включение можно кнопкой «ТЕСТ: 33 C» в потоке Node-RED.
* Приёмник на CTRL-01 принимает данные на `/api/readings` и `/api/actuators`.
* Те же данные параллельно пишутся в SQLite на DB-01 (`telemetry.sqlite3`), веб-интерфейс на `http://192.168.20.12:8081/`.

Логика проверялась на случайных значениях: 234 решения вентилятора, расхождений
с порогом 30 °C — ноль.

## Как запустить

```bash
# CTRL-01
cd ~/practice4/ctrl && docker compose -f compose.yml up -d
curl -s http://127.0.0.1:8080/health

# IOT-01
cd ~/practice4/iot && docker compose -f compose.yml up -d
```

Node-RED открывается с WIN: `http://192.168.30.10:1880`.
